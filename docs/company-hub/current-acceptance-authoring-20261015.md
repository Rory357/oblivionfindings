The original omission is therefore **addressed in source**, with passing focused backend checks, rather than an outstanding implementation request. Browser save/reopen remains to close.

**Implemented contract:** `GET /company-hub/manage/{page}/media/{media}/details?actor_id={currentActorId}` returns `{actor_id, page_id, media}`, where `media` is the existing `HubMediaLibrary::describe()` DTO. It preserves the actual edition ID and removed-but-still-selected items for an authorised editor. Missing/invalid actor is 422, changed actor 409, and current edit/foreign-media denial 404. The general library listing paginates 60 items and separates active/removed states, so first-page matching would have been insufficient; document context intentionally chooses the highest referenced edition of a root, which is unsuitable for hydrating an exact older File block. `HubSelectedMediaDetailsTest.php` passed all five cases /49 assertions, covering exact editions/private-field omission, actor validation, reader/foreign-page denial, removed selected files without mutation, withdrawn edit permission and approved-site limits.
