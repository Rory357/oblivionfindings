**I’ve paused implementation until you approve this list.**

The main gap is that individual features exist, but some complete journeys still feel unfinished. For example, **PDF upload exists inside the page editor**, but there is no clear “Upload document” journey or built-in PDF reading experience.

This is the completion list I recommend.

**Company Guides, documents and uploads — highest priority**

1. **A proper Company Guides landing page** — searchable guides, categories, collections, featured guides and recently updated content. Currently, it mainly acts as a menu of individual guide links.

2. **Clear creation buttons** — “Create guide”, “Upload document” and “Add useful link”. Uploading a simple PDF should not require understanding the page designer.

3. **An in-Hub PDF reader** — open a document with page navigation, zoom, search, print and download, with an obvious return to its guide.

4. **Office document support** — upload and download Word, Excel and PowerPoint files. PDF would get the integrated reading experience first.

5. **A complete upload experience** — drag and drop multiple files, upload progress, cancel, retry and clear file-size/type messages.

6. **Proper document cards and details** — meaningful title, filename, file type, size, description, owner, last updated date and review date.

7. **Replace and update documents** — a clear replacement action, document history and recovery, while preserving the link staff already use. Page history already exists; this makes document updates understandable.

8. **Consistent attachments throughout the Hub** — the same polished attachment experience in guides, stories, events and other supported content, with reuse from the existing media library.

9. **Better document search** — find documents by title, description and text inside text-based PDFs. Scanned-document recognition would be a separate addition.

10. **Save the exact document** — clearly distinguish saving a guide from saving one of its attachments. Currently, saving a resource file saves its parent guide.

11. **Richer guide and story writing** — formatted text, headings, lists, tables and inline links, alongside the existing image and content blocks.

12. **Complete guide information** — clear ownership, contact/help actions, review dates, related guides and related documents. Some supporting features exist, but the current guide still displays missing ownership and review information.

**Existing Hub areas to finish and connect**

These already have functionality; this pass would complete their practical workflows and presentation.

13. **News and stories** — polished reading pages, attachments, author details, related content and discussion, with a clear writing-to-publication journey.

14. **Events** — complete event details, attachments, registration responses, calendar actions, changes/cancellations and post-event content.

15. **People and teams** — useful profiles, easy contact actions including Copy email, and team spaces that bring together contacts, guides, documents and updates.

16. **Shout-outs and celebrations** — consistent quality across the Home widget, dedicated page, creation experience, reactions and replies.

17. **Ideas, polls and campaigns** — make participation, current status, results and next steps easy to understand.

18. **Services and useful links** — clear destinations and next steps, working connections to existing request workflows, and useful guidance when something is unavailable.

19. **Saved items, Following, Updates and search** — consistent labels, accurate destinations and predictable return navigation.

20. **Announcements and required reading** — proper reading pages for longer content, with clear acknowledgement status and access to related documents.

**Editor quality and completion checks**

21. **Finish the authoring experience** — consistent on-page editing, understandable draft/review/publish controls, and previews that accurately show the saved content. I found that saved previews currently omit file and video descriptions.

22. **Finish every visible state and verify complete journeys** — polished loading, empty, error and permission states; consistent desktop light/dark styling; and checks covering the whole process. For documents, that means **upload → organise → preview → publish → staff find/read/download → replace**.

**My recommendation is to complete items 1–12 first**, then finish the remaining areas against this checklist. That addresses the practical gaps you are noticing, especially Company Guides and document handling.
