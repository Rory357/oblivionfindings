## §0 LOCKED decisions (from authoritative handoff — do not relitigate)
- **NZ-only.** HSWA 2015, WorkSafe NZ, AS/NZS PPE standards (1801 head, 1337 eye, 1715/1716 RPE + fit-testing, 2210 footwear, 4602 hi-vis, 1891 fall arrest), NZS 8134:2021. en-NZ dates, NZD.
- **Web-only.** No phone frames / mobile treatments.
- **Semantic tokens only.** Zero raw hex/oklch/`bg-amber-500`/`border-l-*`. (Only sanctioned exception: the on-dark hero buttons with the existing `eslint-disable` copied from the kit.)
- **Compose existing components** — do NOT introduce a 2nd hero/tab/menu/modal/field primitive. Use hs-hero-kit, rostering TabStrip/ShiftContextMenu/EntityFilter, register-row-kit, workflow-ribbon, hs-detail-dialog/event-detail-dialog, wizard primitives/shell, add-client-dialog as the wizard reference.
- **Modal-first.** Never navigate to a full-page form. Create/edit/action all modals → POST existing/new endpoint → `preserveScroll` partial reload. Filters/tabs/detail open-close are `router.get` partial reloads (`preserveState`,`preserveScroll`,`replace`).
- **Gating kept:** `hazards.view` (index), `hazards.manage` (mutations). Return `can: { manage }`.
- **4 models / 1 controller:** `PpeType` (catalogue), `PpeInventory` (stock), `PpeAllocation` (issue to worker), `PpeInspection` (inspection record).
- **Reuse, don't replace, existing endpoints:** index, storeType, storeInventory, updateInventory, allocate, returnPpe, storeInspection.
- **New endpoints to add:** `updateType` (PUT types/{type}); type activate/deactivate; `acknowledge` (POST allocations/{allocation}/acknowledge — cols `acknowledged`/`acknowledged_at` already exist, add `acknowledged_by`); `condemn` + `dispose` (POST inventory/{inventory}/condemn|dispose — write status + reason + audit cols).
