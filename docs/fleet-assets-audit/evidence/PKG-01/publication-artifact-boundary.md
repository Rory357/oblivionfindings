# PKG-01 — published evidence and local artifact boundary

The source package and approved additive design guides are committed. The accompanying context includes the exact Main-owned snapshot, Designer's canonical page, handoff/contracts/QA and retained issue/review history, selected test/build logs, and raw-file-to-Git-blob identity mappings. Earlier records retain their original dates, local paths and then-current statuses; the latest canonical page and integration checkpoint take precedence for current status.

The v1–v8 prototype source, screenshots, temporary build output and synthetic browser fixtures remain local. Published artifact manifests identify those locally retained materials for provenance; they do not mean the referenced images or preview source are present in this repository. Frozen v8 was not modified or republished. Machine-specific PHPUnit/runtime profiles, credentials, browser-seed.php, storage data, executable local repair scripts and raw downloaded baseline GitHub logs are excluded. Six historical non-executable implementer records are included after inspection; their older status claims are historical.

Main's test-server publication approval authorizes the reviewed package's merge/push and normal test-server automation. It does not approve production activation, actual safety-policy values, reviewer grants or final page acceptance. Main's older dirty working tree, local main ref and unrelated public/.user.ini remain outside this package.

An initial integration regression invocation through Artisan was interrupted when its wrapper supplied a duplicate configuration option; no test result from that attempt is counted. Source inspection showed the wrapper prepends the ordinary configuration, then appends the explicit forced package configuration, and PHPUnit takes the last configuration argument. The verified direct Pest rerun uses exactly one explicit phpunit.pkg01.xml. Only the existing browser PHP server remained after interruption. No runtime profile or trust setting was changed to hide this warning.
