# v12 action-completeness audit

The user found that Files & follow-up offered an expiry reminder but kept expiry entry elsewhere. This focused audit followed document, reminder, compliance and servicing actions for the same disconnect; it is not a production-readiness certification.

## Gaps corrected

1. **Expiry separated from its action.** Expiry now sits beside renewal, with conditional date/time, searchable owner and backup. Required-field errors remain on that step.
2. **Fixed reminder defaults.** Users choose timing and responsibility instead of an automatic 09:00-on-expiry task. Past or post-expiry renewal times are rejected. Expired documents can receive a general follow-up through Reminders.
3. **Optional dates could not be removed.** Optional operation dates have Clear date. Selecting renewal makes expiry required; unchecking it pauses an existing renewal.
4. **Uploads lost page context.** Insurance, warranty and ownership rows preselect type and known reference/cover date. Profile and document dates remain independently owned, with mismatches visible.
5. **Saved files had no metadata edit.** Edit details & expiry reuses the wizard without replacing file content. Reasons and old/new expiry appear in vehicle history.
6. **Replacement could orphan or duplicate reminders.** One document set has one renewal task. Replacing retains originals as Superseded and transfers the active task with its ID/history. Metadata edits reuse the task. Completed history stays with its original version. Archive can explicitly pause renewal.
7. **Document sources were absent from reminder creation.** Current documents are searchable sources. Document renewal Edit/reschedule opens its expiry step. Library entries show status/date and link to the calendar. Schedule and mileage evidence return to their respective source sections.
8. **Compliance uploads omitted due-date updates.** Update dates & evidence is visible on each row. Add evidence and Upload document open the source-owned wizard with certificate, date/range and reference together.
9. **Conditional compliance requirements were misleading.** Required references/dates no longer say optional. Not applicable needs its basis, with no invented certificate/range/expiry and no due reminder. Needs assessment can be recorded without a fabricated RUC range. Restriction/release boundaries remain.
10. **Work outcome had no report upload.** Completion/retest attachments are accepted directly. Either a reference or uploaded evidence is required. File IDs supply the saved reference when text is blank; files appear in the work order and library. Completion updates next service but does not release restricted use.
