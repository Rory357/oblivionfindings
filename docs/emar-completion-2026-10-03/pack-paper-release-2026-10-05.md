# Pack stock and historical-dose recovery

This release pass integrates physical pack evidence with medication recording, controlled registers, transport, counts and historical paper reconciliation. It is for desktop web. Production has not been migrated or enabled from this branch.

## Implemented contracts

- Pack receipts, current balances, explicit waste, counts, corrections, returns and destruction retain exact medicine, pack, quantity and revision evidence. Physical stock and usable stock are displayed separately. Opening a legacy balance retains unknown original batch, receipt and expiry facts as unknown.
- Controlled receipts and openings retain the existing stock and controlled-record capabilities, current house presence and a separate eligible witness. Disposal can remove retained physical stock from an unsuperseded ceased order; it does not reopen administration or receipt authority.
- Transport records exact outward allocations. Recording a trip dose does not deduct house stock twice. Returns restore only actual returned quantities; declared missing quantities remain visible in loss investigation. A fully accounted-for trip can finish while that investigation remains open.
- Paper collection retains the signed actual clinical and physical facts, including unknown values. Posting requires complete facts, giver confirmation, required historical second-person evidence, current authority, historical authority and the canonical clinical checks.
- Historical stock settlement explicitly chooses a new exact deduction or an already covering reviewed count. Independent closing quantities, count coverage, revisions and each prior settlement review are retained. A closing count cannot silently deduct the same paper dose again.
- An expired emergency grant cannot be revived by a submitted timestamp. A separately accountable current reviewer may verify retained server evidence of historical coverage; this creates paper-recovery evidence, not a new live grant.
- Connected recording has a signed 30-minute review context tied to the worker, medicine, house, order and stock setup. Pack-tracked given doses require connected validation; older actual or offline facts go through reviewed paper recovery. Exact accepted retries remain duplicate-safe.
- The main stock hub now exposes **Packs & counts**, using existing stock access. The pack workspace links back to the stock overview and preserves the person and house selection. All six pack views, counts, movements, pharmacy choices and summary figures use the selected person's scope. Existing stock/pharmacy functions are retained.
- If a receipt or opening response is interrupted, the form retains the original instruction and request identity. A controlled receipt lets the same witness re-enter their PIN without changing the stock instruction. Leaving an unconfirmed save refreshes the current stock history and warns against starting another receipt before checking it.
