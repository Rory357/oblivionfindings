Chat v3 · pop-up kit

Every Chat pop-up on the app’s pop-up kit: one frame, the kit widths, the same states. Message actions stay a hover bar and one menu.

Light

The kit Chat usesPOPUP_STYLE_GUIDE.md · Form, Confirm, Side panel, menus and toasts · widths 480, 720, 900 only

Form · 480

Lens, title, one line, ✕. The record it came from as a plain line. Grey footer: Cancel first, the main button last and named for what it does.

Confirm · 480

A question that names the thing. No ✕; Esc and Cancel close it. Red only when something is deleted or a safety check is loosened.

Side panel · 480

Message info and threads, on the sky head, beside the conversation. Read-only parts never become a pop-up.

Menus and toasts

Message and conversation actions, mute and “Delete for me” are menus with an Undo toast. A pop-up only when there is a form to fill.
