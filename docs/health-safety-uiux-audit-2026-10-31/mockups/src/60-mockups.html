6 · Mockups

The redesigned pages, drawn as they will be built

Each board draws one screen at 1440 px with the app's current light tokens (the colour refresh is paused), the Event Horizon header, the signature blocks, StatusBadge tones and the pop-up kit. Example people and houses are made up. Use "Full size" to see a board at 1440 px.

A dashed outline marked with a decision number (for example Q2) shows a button that waits on that decision; every other button is one the server allows today for that person. Patterns on every board: rows open on click; ⋯ and right-click carry the same items; the next step is a button on the row; blocked actions are shown disabled with the reason; every number links; empty, loading and error states are drawn; dates use the approved calendar and clock pickers; finishing something asks for an outcome note.
