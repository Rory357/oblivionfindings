## Agreed foundation seam

`reserveDirect(ItTicket|ItTicketComment $parent, array $files, User $actor)` returns readonly reservation references `{id, uuid, path}`. The independently committed technical row binds the exact parent morph/ID, actor and file fingerprints without foreign keys to the outer transaction's locked/uncommitted records. It writes no bytes. `storeReservedDirect(parent, files, actor, reservations, &$storedPaths)` locks the exact intents inside the business transaction before writing their fixed paths and creating canonical `ItAttachment` rows. Storage/intent implementation belongs to W00; callers must not reproduce it.

`requestRollbackCleanup(reservations)` is nonthrowing and records durable cleanup only after the outer transaction has ended. If any outer transaction remains, it returns deferred evidence and retains the committed reservations. This is necessary because InnoDB savepoint rollback can retain row locks: a second connection must not wait on the caller's own surviving locks. `retryPending()` processes only explicitly authorized pending intents; neither age nor a missing receipt authorizes deletion.
