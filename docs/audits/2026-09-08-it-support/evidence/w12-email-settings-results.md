Explicit array/log sinks remain local. Both link-only and full public-reply modes are selectable; unchanged default is link-only. No production provider has been enabled.
- Configuration tests use the canonical delivery ledger and an actor-owned request UUID. Same-request recovery does not create another delivery, including after configuration changes. Pending/uncertain sends block a new test. The UI distinguishes local capture, accepted, delivered and uncertain results.
- The settings page and edit wizard use approved shared components. Recovery retains drafts and version review; current actor/permission denial conceals settings. Known unsubmitted test rejection requires a fresh settings read; unknown response retains the same request identity.
- Review identified and repaired a retry gap: retry commits a durable dispatch intent and uses the existing post-response/scheduled drain, with no mail side effect inside the caller transaction. Explicit API rejection is distinct from ambiguous acceptance. The final pre-submit listener rechecks the selected mailbox, including for SMTP.
