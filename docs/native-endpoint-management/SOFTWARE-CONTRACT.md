# Native machine MSI contract v1

Single operating organisation; current roles, approved Sites, Device assignment and agent incarnation authorize this capability. Execution shipping gate is disabled. Site collectors cannot install computer software.

Capability `endpoint.software.install`. Endpoint credential only. Fixed routes GET `/api/endpoints/agent/software`, GET `/software/{attempt_uuid}/artifact`, POST `/software/{attempt_uuid}/claim`, POST `/software/{attempt_uuid}/result` under `/api/endpoints/agent`. No client URL, path, arguments, MSI properties, transforms or patch input.

Signed dispatch has exactly13 keys: version(1), type(endpoint_software_install), agent_uuid, command_uuid, attempt_uuid, assignment_fingerprint, capability, parameters, policy, technician, purpose, issued_at, expires_at. Parameters exactly10: package_uuid, package_version(immutable integer revision), sha256, size_bytes(1..536870912), signer_sha256(certificate DER), product_code(uppercase braced GUID), product_version(major.minor.build, <=255.255.65535), architecture(amd64|arm64), display_name, publisher_label. Policy exactly3: version, enabled(true), consent_mode(attended|unattended). Labels <=200 Unicode scalars; purpose<=500. UTC timestamps exactly yyyy-MM-ddTHH:mm:ssZ, dispatch <=24h. All schemas closed; no null except explicitly named. Ed25519 original bytes; payload<=16384.

Only reviewed self-contained machine MSI: exact signature chain+signer/hash/size, ProductCode/ProductVersion, ALLUSERS=1, machine context, x64|Arm64 Summary Template, embedded compressed sources. Custom actions remain privileged reviewed code; signature is not a safety guarantee. Vendor `/i` upgrade only; reject same ProductCode equal/higher current version. Fixed trusted-system msiexec `/i <protected package> /qn /norestart REBOOT=ReallySuppress MSIRESTARTMANAGERCONTROL=Disable`. No automatic reboot, reinstall switches or caller property. Staging verification precedes claim, and protected same bytes remain locked through process creation.

Poll exact {command: envelope|null}. Artifact is authenticated same-deployment bytes, no redirect, exact bounded size/hash. Claim request exactly4 unattended or5 attended: command_uuid,payload_hash,artifact_sha256,boot_id,consent? {desktop_session:UUID,consent_nonce:64lowerhex}. Signed claim exactly15: version(1),type(endpoint_software_claim),agent_uuid,command_uuid,attempt_uuid,assignment_fingerprint,payload_hash,policy_version,consent_mode,artifact_sha256,boot_id,desktop_session(null unattended),consent_nonce(null unattended),issued_at,expires_at. Fresh <=30s, exact replay no renewal. Current authority/policy/catalogue/consent rechecked. No execution while another governed mutation is unresolved.

Result exactly8: command_uuid,payload_hash,status,mutation_started,reason_code,exit_code(nullable uint32),reboot_required,boot_id(before process). Status awaiting_observation|failed|uncertain|declined|expired. 0 =>awaiting_observation/installed,false reboot;3010 =>awaiting_observation/installed_restart_required,true reboot;1641 =>uncertain/restart_initiated,true reboot;1618=>failed/installer_busy; other known exit=>failed/installer_failed. Known child exits have mutation_started=true. Declined/expired and preflight failures false/null exit. Unconfirmed claim response uses uncertain/state_unavailable,false; interrupted process boundary uses uncertain/interrupted,true. Lost process/claim boundaries remain uncertain and never repeat. Result ACK exact command_uuid,attempt_uuid,payload_hash,accepted(true).

Heartbeat `software_actions` exact version(1),installed_service(true),release_enabled(true),executor(windows_msi); absent clears readiness. `software_observations` <=8 exact command_uuid,attempt_uuid,product_code,product_version(nullable),state(installed|advertised|absent|unknown),boot_id,transaction_quiescent(bool),observed_at. Machine MsiGetProductInfoEx product state/version independently queried after receipt; never Win32_Product/registry display alias. Quiescence requires exact own child ended plus independent Windows Installer inactivity; unknown spawn identity after crash requires changed boot. Ordinary mutex absence is insufficient. ACK `software_observations_accepted` <=8 exact same8 plus status(succeeded|uncertain), bound exact sent observation. Unknown/busy not accepted. Only0/3010 plus fresh quiescent installed exact desired version succeeds. Crash attribution remains uncertain. Accepted eligible evidence may release physical mutation exclusion; it is not permission to repeat installation.

Protected durable journal persists process-entry marker BEFORE CreateProcess, then suspended child PID+creation time BEFORE ResumeThread. No kill-on-service-exit job, timeout kill, or blind retry. Crash/restored unresolved work latches gate before other mutation workers. Recovery reporting/product observation continues after release/catalogue withdrawal. Retire only acknowledged terminal expired records with eligible physical-quiescence evidence; persist retirement watermark before new work.

Local view exactly22: protocol,server_origin,status,command_uuid,attempt_uuid,payload_hash,consent_token,policy_version,consent_mode,technician,purpose,package_name,package_version,product_version,publisher,architecture,size_bytes,expires_at,reason_code,mutation_started,reboot_required,can_decline. Status idle|staging|requested|installing|awaiting_observation|succeeded|failed|uncertain|declined|expired. Token only requested; only requested can_decline. Idle empty/zero/false. Requested requires future expiry; entered and terminal states may survive expiry. software_poll3 request keys version/operation/expected_origin_hash; software_decide7 adds attempt_uuid/payload_hash/consent_token/decision allow|decline. Explicit Allow authorizes this one reviewed install; closing afterward does not cancel. Current verified unlocked OS SID/logon/session required at actual launch. UI labels no paths/secrets/raw MSI output. Succeeded requires serveraccepted independent product evidence;3010 retains restart-required notice for separate governed restart.

Reason codes: staging,ready,installing,installed,installed_restart_required,installer_busy,installer_failed,restart_initiated,artifact_unavailable,artifact_invalid,signature_invalid,product_mismatch,architecture_mismatch,already_installed,downgrade_denied,policy_unavailable,consent_lost,declined,expired,interrupted,state_unavailable,operation_failed. First3 local only.

Operational acceptance still requires signed installed SYSTEM service on Windows amd64/arm64 VM, real reviewed MSI/signature/revocation tests, process/service crashes, Windows Installer busy/rollback/reboot cases and no-force/release withdrawal behavior. Injected checks do not establish that operational acceptance.

Restart-required evidence is durable and boot-bound:3010 notice is not retired or erased by acknowledgement, lease expiry, local dismissal or another install. A renewed independently accepted exact product observation on a later boot marks it acknowledged. Physical exclusion may release on the initial quiescent product acceptance so a separately approved restart can proceed. No automatic restart is introduced.

Software-specific local responses are bounded at32768 bytes. `installing` with mutation_started=false means preparation/final authority in progress, not proof of MSI execution. Current MSI ProductCode equal/higher-version check is repeated immediately before process creation; cross-ProductCode downgrade/upgrade relationships still require reviewed vendor package governance rather than a claim of generic version discovery.
